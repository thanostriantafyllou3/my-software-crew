# Resume

1. Find the project's `MESSAGEBOARD.md` (newest entries first) and `PLAN.md`; if there are several, use the one for the sub-project the user names.
2. Read the newest message-board entries until you reach a completed milestone, then the plan's scope, open decisions and next steps.
3. Check that what they claim still holds: files and functions named exist, tests pass. Note anything stale.
4. Tell the user in a few lines: where things stand, what is open for them to decide, and the next step you propose. Then wait for their go-ahead on anything that is theirs to decide.
